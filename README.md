# Worldforge Maps

Preciso criar um app pessoal, é meio simples, é para ver um mapa, onde no mapa vai ter nações, e quando eu clicar nas nações eu vou ver informações delas, se é aliada, inimiga, neutra, tratados, observações e etc

O mapa inicialmente vai ser limpo e eu vou preenchendo ele, com a minha nação e as outras macies, podendo fazer rotas, estradas, portos, cidades, capitais e fortes

Tudo é modificavel, estilo Minecraft, eu posso colocar mapas em todos
